# Online Shopping Website

## Project Overview
This project is a simple and aesthetic online shopping website interface created as part of a web development assignment. It presents products in a responsive grid and includes product details, prices, discounts, ratings, categories, and shopping buttons.

## Features
- Shopping navigation bar
- Promotional banners and offers
- Responsive product grid
- Product categories
- Product names and descriptions
- Prices and discount labels
- Customer ratings
- Shopping buttons
- External CSS stylesheet
- Simple, clean, and aesthetic layout
- No JavaScript used

## Technologies Used
- HTML5 — webpage structure
- CSS3 — styling, layout, and responsive design

## Project Structure
```text
Online-Shopping-Website/
├── index.html
├── style.css
└── README.md
```

> The filenames above are a suggested structure. Update them if your project uses different filenames.

## How to Run
1. Download or copy the project files into one folder.
2. Make sure the HTML file links to the external CSS stylesheet.
3. Open `index.html` in a web browser.

## Customization
- Add or edit products in the HTML file.
- Update prices, discounts, ratings, and descriptions as needed.
- Change colors, spacing, and responsive layout in `style.css`.
- Replace promotional banner text with current offers.

## Assignment Objective
To create a user-friendly e-commerce interface that displays product information clearly and provides a responsive shopping layout using HTML and external CSS, without JavaScript.
